Scrapheap

Welcome to Scrapheap, a community-driven alternative format for Neuroscape TCG that puts the focus on creativity, accessibility, and deck-building ingenuity.

In a world where the biggest corporations hold all the cards, Scrapheap is where the streets fight back. This format challenges divers to build competitive decks using a more accessible card pool, giving overlooked cards and unconventional strategies an opportunity to shine.

SEC 01

Legal cards

// CR 100.2a

Play is constructed Neuroscape. Scrapheap adds one limit. The cyberdeck, the RAM deck, and the sideboard’s non-mainframe cards are commons. The mainframe can be any rarity, including the optional one in the sideboard. Basic RAM is legal in any number.

Slot Legal cards
Cyberdeck 50–255 commons. No RAM. No mainframe.
RAM deck Exactly 25. Common RAM, plus any number of Basic RAM.
Mainframe Exactly one, in the mainframe zone. Any rarity.
Sideboard Up to 12 commons, plus one optional mainframe of any rarity. None of the 12 can be RAM or a mainframe. May be empty.
SEC 02

Rarity

// CR 210.1e

A card is common here when a printing has rarity code C, to the right of the set symbol. The faction hex for a common is copper or bronze. Tokens use that fill too. Their code is T.

Any printing of a common is legal, including a promo or an art rare. A card printed only above common is not, unless it is a mainframe.

Code Printed as Scrapheap
C Common Legal. Any printing.
B Basic Basic RAM in the RAM deck. Any number.
U Uncommon Legal if it is a mainframe, or a common printing exists.
R Rare Legal if it is a mainframe, or a common printing exists.
QR Quantum rare Legal if it is a mainframe, or a common printing exists.
AR Art rare Legal if it is a mainframe, or a common printing exists.
SC Source code Legal if it is a mainframe, or a common printing exists.
P Promo Legal if it is a mainframe, or a common printing exists.
T Token Not a deck card.
SEC 03

Mainframes

// CR 303

You start each game with exactly one mainframe in the mainframe zone. It is never in play (CR 303.1, CR 303.8). It can be any rarity. So can the optional mainframe in the sideboard. Declare which one you are using at the start of each game (CR 100.3).

Only a card with the card type mainframe is exempt. A rare character, program, gear, or RAM card is still illegal.

SEC 04

Deckbuilding

// CR 100.4
  • Four copies. No more than four of a name across the cyberdeck, sideboard, and RAM deck. Basic RAM is exempt (CR 100.4). A card that allows more than four may also use those copies in the sideboard (CR 100.4a). The rulebook only counts the cyberdeck and sideboard. This format follows the Comprehensive Rules.
  • Between games. Swap among the cyberdeck, the mainframe, and the sideboard only. The RAM deck stays as built. The deck you start the next game with still has to be legal.
  • Iconic. Same four-copy limit. You cannot control more than one iconic object with the same name (CR 205.4b).
  • Factions. No extra faction limit.
  • Ban list. None in rev 1.0. Changes get listed on this page first.
  • Limited. Draft and sealed are not Scrapheap. Those use a 30-card cyberdeck minimum (CR 803, CR 804).
